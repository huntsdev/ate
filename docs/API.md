# Phase 0 API

FastAPI/Pydantic is the contract authority. The checked-in
[OpenAPI document](../packages/contracts/openapi.json) generates
[frontend types](../apps/web/src/lib/api.generated.ts). No business routes exist.

| Route | Success | Failure / dependency behavior |
| --- | --- | --- |
| `GET /api/v1/health` | 200; `status: alive`, `service: ate`, `phase: 0` | Process check; no network calls |
| `GET /api/v1/health/live` | Same as `/health` | Explicit liveness alias |
| `GET /api/v1/health/ready` | 200; `status: ready` | 503; `status: not_ready` when a required dependency fails |

Readiness returns `dependencies.postgres` and `dependencies.redis`, each
`healthy` or `unavailable`. It executes `SELECT 1` and Redis `PING` concurrently
under a per-probe deadline (default two seconds, configurable 0.1–10 seconds).
Driver connection/socket/statement/pool limits further bound resource use.
Liveness stays available through dependency outages. The process does not
contact Elastic or Ollama during startup or health checks.

Health identifies optional providers as `not_enabled`, meaning the Phase 0
application has no integration enabled. It makes no claim about whether a host
Ollama process or optional Compose Elastic service is actually running. Provider
health adapters and degraded integration reporting arrive with their phases.

Responses include `X-Correlation-ID` generated by the server and
`Cache-Control: no-store`. Dependency exceptions and credentials are omitted.
The local foundation has no business-data endpoints or authentication. Do not
publish it to a LAN or internet without the later access-control work.

## Regenerate contracts

From the repository root:

```powershell
uv run --directory apps/api --locked python ../../scripts/export_openapi.py
Set-Location apps/web
npm.cmd run contracts:generate
npm.cmd run contracts:check
Set-Location ../..
```

The exporter uses explicit synthetic configuration and never connects to a
database. Do not hand-edit generated artifacts. After changing response models,
regenerate both files and run the contract checks. CI rejects drift from the
FastAPI source or from the OpenAPI-generated TypeScript.
